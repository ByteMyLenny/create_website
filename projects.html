Engineering Inventory Management System

May 2026 - Aug 2026

Built during my Software/Hardware Engineer internship at BAE Systems, this desktop application automates the process of sorting through thousands of engineering requests to identify which schematics are actually needed for a given project. It compares those needs against a custom-designed SQL inventory database and outputs two reports: schematics missing from inventory that must be sourced, and a full list of schematics needed for the project (on-hand and off-hand).

Key Features

  • Automated parsing of large-scale engineering request forms
  • Custom SQL-based inventory database design
  • Schematic-to-inventory gap comparison
  • Automated generation of "needed vs. on-hand" reports

Raycast-Guided Targeting System

May 2024 - Oct 2024

A personal project built inside a game engine simulating a missile station that tracks and intercepts moving targets. The system raycasts a spotted target and derives position, velocity, and acceleration in both global and body-relative XYZ coordinates, then uses that data to triangulate the target's future position and guide the missile to intercept it. Started as a manually-guided system, then evolved into a fully autonomous guidance system after launch.

Key Features

  • Raycast-based target detection and tracking
  • Position, velocity, and acceleration extraction in global and body-relative coordinates
  • Predictive triangulation of target intercept point
  • Progression from manual guidance to fully autonomous post-launch tracking

Technologies & Skills

C# Vector Math Physics Simulation Coordinate Transformations Autonomous Guidance Logic
